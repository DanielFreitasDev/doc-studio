# Fontes

As fontes desta pasta são versões reduzidas (subconjunto latino, formato WOFF) de:

- **Kanit** — Copyright 2020 The Kanit Project Authors (https://github.com/cadsondemak/kanit)
- **Maitree** — Copyright 2016 Cadson Demak (https://github.com/cadsondemak/maitree)

Ambas são distribuídas sob a **SIL Open Font License, versão 1.1**, que permite uso,
modificação e redistribuição (inclusive em conjunto com software), desde que as fontes
não sejam vendidas isoladamente e a licença acompanhe os arquivos.

Texto completo da licença: https://openfontlicense.org/open-font-license-official-text/

São as famílias tipográficas definidas no Manual de Identidade Visual do Governo do
Ceará 2023–2026 (Kanit para títulos, Maitree para texto corrido).
